# TRACK_free_starter_template.md

## Name

`TRACK_Starter_Template`

## Objective

Create a recoverable and auditable plan for a user request.

## TRACK Chain

```text
request → scope → research → artifacts → validation → final output
```

## Inputs

* user request
* available files
* constraints
* desired output

## Outputs

* scope.md
* source_matrix.csv
* final_output.md
* final_validation.md
* artifact_register.csv
* state_register.csv
* recovery_log.csv

## Tasks

### T1. Interpret request and define scope

Create `scope.md`.

### T2. Research missing information

Create `source_matrix.csv` and `research_summary.md`.

### T3. Create intermediate artifacts

Create the artifacts needed for the user request.

### T4. Validate artifacts

Check completeness, consistency and limitations.

### T5. Generate final output

Create `final_output.md`.

### T6. Final TRACK validation

Create `final_validation.md`.

## Mandatory registers

* artifact_register.csv
* state_register.csv
* recovery_log.csv

## Note

This is a simplified free example. The complete applied TRACK plan library is distributed separately.
