# TRACK — Open Papers

TRACK means **Task Recovery And Checkpointing Knowledge**.

TRACK is a methodology for designing recoverable, auditable and checkpointed task plans for AI agents.

Instead of relying only on an agentic loop, TRACK structures long tasks as:

```text
plan → task contract → artifact → validation → checkpoint → recovery → resume
```

## Open papers

This repository freely shares two working papers:

1. **Task Recovery And Checkpointing Knowledge (TRACK): A Conceptual Framework for Recoverable Agentic Planning**
2. **Operationalizing TRACK: Experiments, Plan Structures, and Reusable Templates for Recoverable Agentic Workflows**

## What is included here

## What is not included

The complete applied TRACK plan library is not included in this public repository.

The full applied library may include templates for:

* Python code generation
* Python debugging
* literature review
* mathematical modeling
* applied research
* maintenance work order analysis
* FMECA / AMFE
* maintenance planning
* predictive maintenance
* RCM analysis

## Core idea

**Loop makes agents continue. TRACK helps agents not get lost.**
